BÀI 20 — 2076. Process Restricted Friend Requests — Hard
class Solution(object):    def friendRequests(self, n, restrictions, requests):        """        :type n: int        :type restrictions: List[List[int]]        :type requests: List[List[int]]        :rtype: List[bool]        """        pass


Có n người, đánh số từ 0 đến n - 1, ban đầu chưa có quan hệ bạn bè.

Mỗi cặp [x,y] trong restrictions quy định rằng x và y không được kết nối trực tiếp hoặc gián tiếp thông qua chuỗi quan hệ bạn bè.

Xử lý lần lượt các yêu cầu [u,v] trong requests:
- Chấp nhận nếu thêm quan hệ không vi phạm bất kỳ hạn chế nào.
- Nếu chấp nhận, quan hệ được giữ lại cho các yêu cầu tiếp theo.
- Nếu từ chối, mạng lưới không thay đổi.
- Nếu hai người đã là bạn, yêu cầu vẫn được chấp nhận.
Trả về danh sách boolean cho biết kết quả từng yêu cầu. LeetCode

Ví dụ:
Input:
n = 3
restrictions = [[0,1]]
requests = [[0,2],[2,1]]
Output: [true,false]

Giải thích: Sau khi 0 kết bạn với 2, chấp nhận [2,1] sẽ khiến 0 và 1 kết nối gián tiếp.
Input:
n = 5
restrictions = [[0,1],[1,2],[2,3]]
requests = [[0,4],[1,2],[3,1],[3,4]]
Output: [true,false,true,false]

Ràng buộc:
2 <= n <= 1000
0 <= restrictions.length <= 1000
1 <= requests.length <= 1000
Mỗi cặp chứa hai chỉ số khác nhau trong [0,n-1].
